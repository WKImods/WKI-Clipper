# Sound cue assets

All five sounds are released under **CC0 1.0 Universal (public domain dedication)** -
https://creativecommons.org/publicdomain/zero/1.0/ . Attribution is not required; it is given as a courtesy.

The files in this folder are mono 16-bit 44.1 kHz PCM WAV conversions of the originals
(levelled to about -6 dBFS, 0.14-0.5 s). They are embedded into the WKI Clipper executable.

| File | Used for | Source | Original file |
|------|----------|--------|---------------|
| `clip_saved.wav` | Clip / GIF save started | Kenney, "Interface Sounds" 1.0 - https://kenney.nl/assets/interface-sounds | `confirmation_001` |
| `recording_started.wav` | Manual recording started | Kenney, "Interface Sounds" 1.0 - https://kenney.nl/assets/interface-sounds | `maximize_003` |
| `recording_stopped.wav` | Manual recording stopped | Kenney, "Interface Sounds" 1.0 - https://kenney.nl/assets/interface-sounds | `minimize_003` |
| `error.wav` | Save refused / failed | Kenney, "Interface Sounds" 1.0 - https://kenney.nl/assets/interface-sounds | `error_008` |
| `screenshot.wav` | Screenshot saved | "Camera" by themightyglider, OpenGameArt - https://opengameart.org/node/73696 (itself derived from the archive.org item "Camera Shutter Sound" - https://archive.org/details/CameraShutterSound), trimmed to 0.5 s | `photo.ogg` |
